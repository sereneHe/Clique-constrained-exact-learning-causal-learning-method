# INSURANCE benchmark

- `insurance.bif`: standard INSURANCE Bayesian network from the bnlearn repository.
- `samples_seed2027_n5000.csv`: 5,000 ancestral samples generated from the BIF CPDs with seed 2027; categorical states are encoded as integers.
- `adjacency.csv`: reference directed adjacency matrix in `variables.txt` order.
- `variables.txt`: stable variable order used by the data and adjacency matrix.

Source: https://www.bnlearn.com/bnrepository/discrete-small.html#insurance
